11 个课程入口
课程使用原则

文档中标注为第三方转载的 Simon Task 1 与杨帅口语合集仅作为备用；若链接失效，可按课程名在 B 站站内搜索。不要为“配套讲义”购买来历不明的资源。课程是辅助，必须搭配真题练习和纠错。

每四周量化复盘

听力、阅读记录原始正确题数（每套 40 题）；写作与口语记录真实表现。不要把单次练习分数直接当作官方 Band。

阶段检查清单

调整规则（来自你的计划）
  • 听力若连续两个月仍大量漏数字和词尾：改为短音频精听、跟读与纠错，减少泛看视频。
  • 口语若仍无法连续说 60 秒：每天从阅读/写作日借 5 分钟做 P1 即答，总学习时间不变。
  • 每月完成一篇 Task 2 和一篇 Task 1，并按任务回应/完成度、连贯衔接、词汇、语法检查；尽量争取合格反馈。
  • AI 反馈可辅助自查，但不能当作官方分数或专业写作批改的替代。

考试窗口：2027.09—2028.06

2027.09–10
根据 52 周数据做首次模拟；两周一套听读完整限时测试（可拆天），写作与口语尽量获取人工反馈。

接近目标再考虑首考。

2027.11–12
薄弱科目专项：听力拼写/地图、口语 Part 3 解释、写作论证；每月一次四科分拆模拟。

模考稳定再选择考试。

2028.01–02
错题复做、表达自然化、按当季口语题库练习；每周保持两次听力、两次口语。

成绩不足时不冲动报名。

2028.03–04
每两周检查四科；写作按评分标准找合格教师批改，口语模拟面试。

尽量提前 6–8 周确定日期。

2028.05–06
考前 4–6 周进行听读限时、写作计时和口语即时表达；最后一周减量。

按真实模考表现决定最终考试。

每日模板

听力主日

旧词复习 → L0/L1/L2 或音频技巧 → 剑雅一小节/定点精听 → 跟读录音 + 错因

阅读主日

同义替换 → 阅读课/文章结构 → 一篇分段或限时 → 定位证据 + 长难句

写作主日

表达复习 → Simon / 顾家北课程 → 段落或整篇拆分 → 自改语法与逻辑

口语主日

跟读热身 → 示范/主题表达 → P1/P2/P3 录音 → 回听重录
